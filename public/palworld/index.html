순수 이동 (제노드란·흑천마·제노그리프) : 차원 도약 + 신속 + 달리기 왕 + 영구기관
이속 +100%. 스태미나 문제를 영구기관으로 막아 장거리를 끊김 없이 갑니다.

타고 싸우는 총기 빌드 (헬가루다·흑천마) : 차원 도약 + 신속 + 전설 + 달리기 왕
전설이 이속 +20%에 공·방 +20%까지 얹어 줍니다. 탑승 중에는 팰의 공격 패시브가 딜에 거의 관여하지 않으므로(내 총이 때립니다) 귀신·양날의 성검을 넣을 이유가 없습니다.

파밍 겸용 (라바드래곤) : 차원 도약 + 신속 + 달리기 왕 + 영구기관
채굴 배수는 파트너 스킬 고정값이라 패시브로 못 올립니다. 그러니 이쪽도 전부 이동으로.

Lv74 이전 현실판 : 달리기 왕 + 전설(교배로 운 좋으면) + 나머지는 비워두거나 전투 패시브
유물 변환기가 열리기 전에는 이속 패시브를 넉넉히 못 씁니다. 달리기 왕만 먼저 박아두고, Lv74 이후에 차원 도약·신속·영구기관으로 갈아끼우세요. 임플란트는 덮어쓰기가 되니 지금 채워둔 칸이 낭비되지 않습니다.

⚠ 전투용 개체와 탑승용 개체는 따로 키우는 게 맞습니다. 흑천마처럼 둘 다 되는 팰은 특히 그래요 — 딜러로 쓸 개체는 냉철함·귀신을, 이동용 개체는 위 조합을 넣으세요. 같은 팰이라도 역할이 다르면 4칸이 완전히 달라집니다.
