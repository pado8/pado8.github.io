서버 전원

집 PC가 최대 1분 안에 받아서 처리합니다. 켜고 끄는 데 1~2분 걸리고, 접속 중인 사람은 모두 튕깁니다. 세이브는 정상 종료로 먼저 저장됩니다.
끄기를 누르면 켜기를 누를 때까지 꺼진 채로 유지됩니다 (집 PC를 재부팅해도 그대로 꺼져 있습니다).
집 PC가 꺼져 있으면 요청은 저장만 되고, PC가 켜지는 순간 실행됩니다. 켜기 요청은 12시간, 재시작·끄기 요청은 30분이 지나면 자동으로 취소됩니다 — 한참 전에 눌러둔 재시작이 부팅하자마자 터지는 걸 막기 위해서입니다.
