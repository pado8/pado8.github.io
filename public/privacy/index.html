개인정보처리방침

적용 대상: aquapado.com(사이트 모음 메인 페이지·팰월드 공략 가이드·페이지 코멘트 도구) · 운영자: pado(파도, 개인) · 제정 2026-10-27

한 줄 요약 — 이 사이트는 회원가입·로그인·댓글이 없고, 이름·이메일 같은 개인정보를 받거나 저장하지 않습니다. 방문 분석 도구와 광고도 없습니다. 언어·테마·체크 표시 같은 설정은 방문자 브라우저에만 저장되고 서버로 보내지 않습니다.

같은 운영자의 다른 서비스는 각자의 방침을 따릅니다: 타르코프 시세 오버레이·탈콥 가이드, 뚝딱툴즈, 알파 개미의 포트폴리오, PoE 시뮬레이터.

수집하는 것브라우저 저장소외부 서비스광고권리·문의

1. 수집하는 것

  • 방문 분석 도구(Google Analytics 등), 추적 쿠키, 자체 방문 집계 코드를 쓰지 않습니다.
  • 입력 양식이 없어 이름·이메일·전화번호·비밀번호를 받지 않습니다. 연락은 방문자가 직접 보내는 이메일이나 GitHub로만 이뤄집니다.
  • 사이트는 GitHub Pages로 호스팅되며, GitHub이 보안과 운영을 위해 접속 정보(IP 주소 등)를 처리할 수 있습니다(아래 3번). 운영자는 이 기록을 받아 보거나 개인 식별에 쓰지 않습니다.

2. 브라우저 저장소(이 기기에만 남는 것)

아래 항목은 브라우저의 로컬 저장소(localStorage)에 저장되며 서버로 전송되지 않습니다. 브라우저 데이터를 지우면 함께 삭제됩니다.

페이지저장하는 것
포트폴리오 메인선택한 언어(한국어/영어)와 화면 테마(밝게/어둡게)
팰월드 가이드선택한 덱, 지도 표시 설정, 지도 핀 위치 보정값, 직접 올린 지도 이미지. 지도 이미지는 파일을 고르거나 붙여넣었을 때만 이 브라우저에 저장되고, 업로드되지 않습니다. "이미지 제거" 버튼으로 바로 삭제할 수 있습니다.

3. 외부 서비스

페이지를 표시하려고 아래 서비스에서 파일을 받아 옵니다. 이때 브라우저가 해당 서비스에 통상적인 접속 정보(IP 주소, 브라우저 종류 등)를 보내며, 각 서비스의 개인정보 정책이 적용됩니다.

jsDelivr글꼴(Pretendard) 파일

본문에 있는 다른 사이트 링크(프로젝트 페이지, 팰월드 자료 출처 등)는 누를 때만 이동하며, 이동한 사이트에서는 그 사이트의 방침이 적용됩니다.

4. 광고

현재 이 사이트에는 광고가 없습니다. 앞으로 팰월드 가이드처럼 공략 페이지에 광고(Google AdSense 등)를 붙이게 되면, 붙이기 전에 이 항목을 먼저 갱신해 어떤 쿠키가 쓰이는지와 끄는 방법을 적겠습니다.

5. 이용자 권리·문의

  • 운영자가 보관하는 방문자 개인정보가 없으므로 열람·삭제를 요청할 기록이 따로 없습니다. 브라우저 저장소의 내용은 방문자가 브라우저 설정에서 직접 지울 수 있습니다.
  • 이 사이트는 만 14세 미만을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
