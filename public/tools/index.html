페이지 코멘트 도구

보고 있는 화면에서 영역을 집어 코멘트를 남기면, 선택자·좌표·화면 크기까지 붙은 수정 요청서가 작업 중인 세션으로 바로 전송됩니다.

1. 내 사이트 — 이미 켜져 있습니다

여행 도시에에는 이미 심어 뒀습니다. 페이지 우측 아래 ◎ 버튼을 누르면 바로 켜집니다. 설치도 북마크도 필요 없고, 폰에서도 그대로 됩니다.

  • aquapado.com/travel/ · /travel/kaohsiung/ · /travel/nagoya/

2. 다른 내 사이트에 켜기

그 사이트 HTML 끝에 한 줄만 넣으면 됩니다.

<script src="https://aquapado.com/tools/pick.js?v=7" defer></script>

?v= 숫자는 캐시 무효화용입니다. GitHub Pages 가 스크립트를 10분간 캐시해서, 이게 없으면 도구를 고쳐도 최대 10분간 옛 버전이 뜹니다. 제가 도구를 고칠 때 같이 올리겠습니다.

이렇게 넣으면 방문자에게는 아무것도 안 보입니다. 내 기기에서 한 번 ?apick=on 을 붙여 열면 그때부터 그 기기에서만 ◎ 버튼이 뜹니다.
끄려면 ?apick=off. 개인 페이지처럼 항상 켜두려면 data-open="always" 를 붙이세요.

3. 아무 사이트에서나 (선택)

남의 사이트나 localhost 까지 봐야 할 때만 쓰세요. 데스크톱 전용입니다.

북마크바로 끌어다 놓거나, 북마크를 만들고 주소 칸에 아래를 붙여넣으세요.

4. 쓰는 법

  1. 고치고 싶은 페이지를 엽니다 (내 사이트든 localhost든 상관없습니다)
  2. 우측 아래 ◎ 버튼을 누릅니다 → 위에 검은 툴바가 뜹니다
  3. 요소 클릭 모드에서 고칠 곳을 클릭하거나, 영역 드래그로 범위를 그립니다
  4. 무엇을 고칠지 한 줄 적고 저장 (Ctrl+Enter로도 저장됩니다)
  5. 여러 개 남긴 뒤 복사 → 저에게 붙여넣기
버튼하는 일
요소 클릭마우스를 올리면 파란 테두리로 요소를 짚어줍니다. 클릭하면 그 요소가 지정됩니다
지점십자선이 따라다닙니다. 화면 아무 좌표나 클릭하면 그 자리에 빨간 핀이 꽂힙니다. 요소로 안 잡히는 여백·간격을 지적할 때
영역드래그로 사각형. 끄는 동안 크기가 실시간으로 표시됩니다
목록남긴 코멘트를 보고 지웁니다. 화면에는 주황 번호 핀으로도 표시됩니다
보내기작업 중인 세션으로 바로 전송합니다. 성공하면 목록이 비워집니다. 수집기가 꺼져 있으면 복사로 넘어갈지 물어봅니다
복사클립보드로. 수집기가 없을 때 쓰는 폴백입니다
Esc모드 해제 / 한 번 더 누르면 도구 종료

남긴 코멘트는 그 페이지 주소별로 브라우저에 저장되므로 새로고침해도 사라지지 않습니다. 복사한 뒤에는 목록에서 지우면 됩니다.
